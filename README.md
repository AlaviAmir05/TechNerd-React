# Tech Nerd

Tech Nerd is a practice e-commerce frontend built with React and developed from a Figma design. The project focuses on translating a detailed interface into a responsive, reusable, and user-friendly web application.

## Features

- Reusable React components
- Product categories and organized content
- Product cards and detailed product information
- Clean and consistent visual design
- Layout adapted from the original Figma design
- Responsive behavior for desktop, tablet, and mobile screens

## Technologies

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Git and GitHub

## Project Status (Updating)

This is a frontend practice project. It is not connected to a production backend, database, payment system, authentication service, or real-time API. Product information and other content are provided through static mock data.

## Purpose

The purpose of this project is to practice:

- Building reusable and maintainable components
- Creating responsive layouts
- Improving UI implementation and frontend development skills
- Converting a Figma design into a functional React interface

## Disclaimer

This project is created for educational and portfolio purposes. It is not a real online store, and no real purchases or transactions can be made through the application.
